# Система учета в видеопрокате — База данных PostgreSQL (3NF & Data Vault)

Проект учебной базы данных для лабораторных работ по дисциплине **«Хранилища данных»** (**Вариант 14** — *Система учета в видеопрокате*).

---

## 📂 Содержимое проекта

- `docker-compose.yml` — конфигурация для автоматического развертывания СУБД PostgreSQL и локального веб-сервера.
- `index.html` — интерактивная веб-страница с визуализацией ER-диаграмм обеих моделей (3NF и Data Vault) и спецификацией таблиц.
- `requirements.txt` — файл зависимостей Python для работы с проектом и скриптами миграции/загрузки.
- `sql/` — папка со скриптами инициализации БД:
  - `create_3nf.sql` — реляционная модель в 3-й нормальной форме (схема `3nf`).
  - `create_datavault.sql` — хранилище данных по методологии Data Vault 2.0 (схема `dv`).
  - `seed_data.sql` — первичные тестовые данные для проверки работоспособности.

---

## 🚀 Быстрый запуск через Docker Compose

Проект полностью контейнеризирован и развертывается на любом устройстве одной командой.

### Требования:
- Установленные **Docker** и **Docker Compose**.

### Инструкция по запуску:
1. Клонируйте репозиторий или откройте папку проекта в терминале.
2. Запустите контейнеры в фоновом режиме:
   ```bash
   docker compose up -d
При первом запуске PostgreSQL автоматически выполнит все скрипты из папки sql/, создав обе схемы, таблицы, связи и тестовые данные.
